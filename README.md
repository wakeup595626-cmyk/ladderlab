# LadderLab / 梯形实验室

在浏览器里编写、运行和观察 PLC 梯形图的教学仿真器。

![LadderLab 工作台：启保停示例正在运行，变量表中 Motor 为 TRUE](./docs/screenshot.png)

LadderLab 面向 PLC 入门课程、实验预习和个人练习。它把梯形图编辑、变量表、编译诊断和
逐周期扫描仿真放在同一个网页里，打开即可使用，不需要安装博途或连接真实 PLC。

> LadderLab 是独立教学项目，不是西门子产品或官方替代品，也不兼容 TIA Portal /
> SIMATIC S7 工程文件、专有指令和硬件配置。项目中的“V14 / V21 档案”只表示本仿真器
> 开放的基础指令子集，不等于完整复刻对应版本。

## 三步上手

![三步上手说明：拖入指令、点元件改参数、运行后切换变量](./docs/guide.png)

1. **拖入或点击指令**：在顶部“添加指令”点常开、常闭或线圈，也可以直接拖到程序段里；
   定时器、比较和更多指令从“全部指令”打开。元件之间和线路末端的 `+` 也是插入点，
   点开就能选触点类型或加入并联分支。
2. **单击元件改参数**：点触点、线圈或定时器，就地修改类型、变量名、常开/常闭、地址、
   注释或定时器 PT。拖动元件可换位，拖动程序段左侧手柄可调整顺序；不想用鼠标时，聚焦
   触点后按 ← / → 同样能换位，参数面板里也有「← 左移 / 右移 →」两个按钮。选中元件后
   `Ctrl+C` / `Ctrl+V` 可按顺序复制粘贴。
3. **运行并切换输入**：点“运行”，再打开“变量表”，把输入位切成 TRUE；绿色导线就是
   当前扫描周期的通电状态。

首次进入时，梯形图上方会显示同一条三步教练条；点“载入启保停示例”可立刻得到一个可运行、
可拖动编辑的回路。之后可从右上角“更多”菜单重新打开三步说明。

### 画一条并联分支

1. 点分叉位置的 `+`，选「加入并联分支」；新支路会以虚线草稿出现。
2. 在新支路末尾的 `+` 继续加元件，想加多少就加多少。
3. 画完点支路右侧的「合并分支」，再点主线上要闭合的那个「合」插入点；按 `Esc` 可取消取点。

## 界面结构

- **顶栏**：左侧是撤销 / 重做和项目名称，右侧集中放“新建 / 导入 / 导出 / 运行”主操作，
  导出菜单可选择工程文件、完整程序 PNG 或纯梯形图 PNG；手机端会把这组文件操作收进
  “文件”菜单。改错了直接点顶栏的撤销（Ctrl+Z），重做是 Ctrl+Shift+Z；
- **程序页签**：`Main [OB1]`，右侧可切换变量表；
- **常用指令栏**：常开、常闭、线圈、定时器、比较和“全部指令”；
- **梯形图工作区**：每段固定显示“程序段 1 / 2 / 3…”，编号后是可点击修改的标题、元件、
  并联支路和添加程序段入口；编号随拖动排序自动重排，和博途的习惯一致；
- **状态栏**：运行状态、扫描周期和本地保存时间；
- **按需抽屉**：项目、变量表、实验库、文件、帮助和说明只在需要时打开。

程序图纸默认以 1360px 居中显示。把指针移到图纸左、右边缘，拖动竖向调宽抓手即可加宽或
收窄；双击抓手（或聚焦后按 `Home`）恢复默认宽度，方向键可微调。手机端自动铺满可用宽度。

手机端把“程序 / 指令 / 变量”放在底部导航中，不把所有面板同时挤在首屏。

![手机端首屏](./docs/ui-check.png)

## 主要能力

- 可点击、可拖入、可换位的程序段编辑：触点、并联分支、线圈、置位/复位和指令盒；
- 键盘与鼠标同权：触点 ← / → 换位、Enter 打开参数、Esc 关闭面板，标签页和菜单支持方向键；
- 单击元件就地编辑类型、变量名、常开/常闭、地址、注释和定时器参数；
- V14 / V21 指令档案切换，并对当前档案不支持的指令给出编译诊断；
- 六个可直接运行的课程实验：四路抢答器、定时器与计数器、十字路口交通灯、三层电梯、
  音乐喷泉和装配流水线；
- 浏览器内离线扫描仿真：边沿检测、TON / TOF / TONR、CTU，以及课程需要的
  MOVE / ADD / SUB / SHL / ROL 整数指令；
- 触点、支路、线圈、指令输出和运行时数值的绿色能流高亮；
- 变量表：BOOL / INT 变量、地址、初始值、注释、运行值切换与引用检查；
- 工程诊断、撤销/重做、自动本地保存、`.ladderlab.json` 工程导入/导出，以及带程序段
  信息的完整程序 PNG 和纯白背景梯形图 PNG 导出；
- 内置课程实验与启保停、顺序启动、计数包装、闪烁回路、边沿计数基础示例；
- 纯静态前端，适合部署到 GitHub Pages。

## 快速开始

需要 Node.js 22.12+、24.x 或 26+（CI 使用仓库内 `.nvmrc` 固定的 24.20.0）。
23、25 这类奇数版本不在 `engines` 支持范围内。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址即可。生产构建：

```bash
npm run build
npm run preview
```

提交前可一次运行全部校验：

```bash
npm run check
```

它会依次执行单元测试、类型检查、lint 和生产构建。

## 部署到 GitHub Pages

仓库包含 GitHub Actions 的检查与静态站点部署流程。首次启用时：

1. 确认默认分支为 `main`；
2. 在 GitHub 仓库的 **Settings → Pages → Build and deployment** 中将 Source 选为
   **GitHub Actions**；
3. 推送 `main`；CI 完成测试、类型检查、lint 和构建后才会部署。

应用是纯静态前端，不需要数据库或后端服务。

## 版本档案

版本档案只限制“本仿真器开放哪些指令”，不是对西门子软件版本的兼容性声明。

| 能力 | V14 档案 | V21 档案 |
| --- | --- | --- |
| 常开 / 常闭触点 | 支持 | 支持 |
| 上升沿 / 下降沿触点 | 支持 | 支持 |
| 比较触点 | 支持 | 支持 |
| 线圈 / SET / RESET | 支持 | 支持 |
| TON / TOF | 支持 | 支持 |
| TONR 累计定时器 | — | 支持 |
| CTU 计数器 | 支持 | 支持 |
| MOVE / ADD / SUB / SHL / ROL | 支持 | 支持 |
| PATTERN 教学灯字序列 | 支持 | 支持 |

`PATTERN` 是本项目为音乐喷泉实验提供的通用教学序列扩展，不是西门子标准指令。六个实验
使用普通程序段、变量和指令盒表达，验证的是浏览器教学模型，不等同于 TIA Portal 编译结果或
真实 PLC 行为。

切换档案不会删除现有逻辑；工程使用新档案不支持的指令时，诊断面板会标出问题。

## 仿真语义

LadderLab 按从上到下的顺序执行程序段，每个扫描周期执行以下步骤：

1. 对每个程序段计算触点与并联分支的能流；
2. 写入线圈、置位/复位、定时器和计数器的输出；
3. 更新边沿存储、计时值和计数值；
4. 进入下一扫描周期。

因此，前一个程序段在当前扫描写入的变量可以被后面的程序段读到；同一个 BOOL 变量被多个
普通线圈驱动时，扫描顺序靠后的输出会覆盖前面的结果。这些行为会在诊断中给出提示。

仿真周期由界面调度，不是硬实时 PLC。定时器和扫描时间适合教学观察，不应作为现场控制
或安全评估的依据。

显式配置为字节别名的 BOOL 位与 INT 字节会双向同步。例如在喷泉实验中修改 `Lamp1` 会
更新 `LampByte` 的第 0 位，修改灯字也会同步更新对应灯位。

## 工程结构

```text
src/
  engine/       纯 TypeScript 编译与扫描仿真引擎
  state/        不可变工程编辑操作
  components/   梯形图画布、就地编辑器、顶部工具与按需抽屉
  lib/          JSON 导入导出、本地存储、拖拽与焦点工具
  App.tsx       应用状态、仿真调度和界面组合
```

引擎不依赖 React，逻辑语义应优先放进 `src/engine` 并用测试覆盖；界面只负责编辑、
展示和调度。

## 当前限制

- 不导入或导出 TIA Portal、SIMATIC S7 工程文件；
- 不支持 SCL、SFC、FBD、HMI 组态或完整博途指令集；
- 不与真实 PLC 通信，不提供硬件下载、在线诊断或安全功能；
- 不模拟完整的 IEC 61131-3 运行时、浮点精度、扫描任务和通信协议；
- 编辑与验证均在浏览器内完成，不能替代真实控制器的联调或验收。
