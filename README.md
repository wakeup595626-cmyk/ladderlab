# 梯形实验室 LadderLab

在浏览器里编写、运行和观察 PLC 梯形图，不需要安装博途或连接真实 PLC。

[在线体验](https://wakeup595626-cmyk.github.io/ladderlab/) ·
[使用指南](docs/GUIDE.md) ·
[指令档案](docs/GUIDE.md#指令档案)

![LadderLab 工作台：启保停示例正在运行，变量表中 Motor 为 TRUE](./docs/screenshot.png)

> LadderLab 是独立教学项目，不是西门子产品或官方替代品，也不兼容 TIA Portal /
> SIMATIC S7 工程文件、专有指令和硬件配置。项目中的“V14 / V21 档案”只表示本仿真器
> 开放的基础指令子集，不等于完整复刻对应版本。

## 能做什么

- 在可拖拽、可复制的程序段里放置触点、并联支路、线圈和指令盒，单击元件即可改参数。
- 用变量表、编译诊断和逐周期扫描观察能流；支持 TON / TOF / TONR、CTU、边沿和整数指令。
- 切换 V14 / V21 指令档案，运行六个课程实验，或从启保停、顺序启动等示例开始练习。
- 管理本机项目，导入/导出 .ladderlab.json，工程随时能接着改、换电脑迁移。
- 全部导出为矢量 SVG：完整程序图、纯梯形图、顺序功能图都能存成缩放、打印不糊的
  矢量文件；PNG 只是可选附加位图，贴微信或老版本 Office 时再用。
- 一键导出顺序功能图（SVG 矢量）：从当前梯形图按步骤位、状态位或节拍归纳，纯白底，
  只有步骤、动作和转移条件。
- 「打开项目 → 整包备份」把所有本机工程打包成一个文件，换电脑或清缓存前先存一份。
- 「导出 → 复制分享链接」把整份工程压进一条网址，发给同学点开就能接着改，不用传文件。
- 安装为桌面应用；首次联网加载后可离线打开，工程数据保存在当前浏览器本机。

完整操作说明、快捷键、项目保存、离线安装、仿真语义和浏览器验收步骤见
[docs/GUIDE.md](docs/GUIDE.md)。

## 顺序功能图是怎么来的

顺序功能图不是固定模板，也不是把梯形图逐段翻译成 SFC。导出时，LadderLab 先扫描当前
工程，找“程序确实有状态”的证据，再按证据选一种画法：

- 有置位 / 复位步序或步标记时按步：变量名可写成 Step1…StepN（也识别 S1…SN），或在
  注释里写“第 N 步”；同一字节里的移位寄存器程序按容器位序排步。
- 有状态位自保持（启保停、互锁）时按状态：每个状态用它自己的置位、复位条件连转移，
  互斥关系只作为联锁条件，不合并成一步。
- 有循环节拍或模式表时按拍：单个序列盒（PATTERN）一拍一步；一个自保持位带动定时或
  计数时，按初始 → 运行 → 完成展开。
- 找不到任何可证明的状态证据时，只画一个步骤的「组合逻辑」视图：把各网络的动作和
  前置条件列在同一扫描周期里，不按网络先后编造步骤，也不画假的扫描回边。

图面刻意保持简洁：纯白底，没有标题、图例、页脚或说明文字，只有步骤、动作框和转移
条件；回跳和停机支路走左侧直角折线，动作框里只留简短的动作名和输出地址。它是“按
可识别结构归纳”的参考图：新画的自绘工程同样对应自己的梯形图，但复杂拓扑会被合并或
简化，不保证与教材、老师给的 SFC 或 TIA Portal 的 SFC 严格等价。

## 本地运行

需要 Node.js 22.12+、24.x 或 26+。23、25 这类奇数版本不在 engines 支持范围内。

```bash
npm ci
npm run dev
```

生产构建与预览：

```bash
npm run build
npm run preview
```

提交前可运行 npm run check，依次执行单元测试、类型检查、lint 和生产构建；界面、存储
与导出改动还应运行 npm run test:e2e，或按使用指南完成对应的浏览器回归。

## 数据与边界

应用没有账号、数据库或云同步服务，不会自动把梯形图上传到服务器。清理浏览器站点数据
会删除本机工程，重要内容请导出 .ladderlab.json 备份。

本工具只用于浏览器内的教学编辑与仿真。顺序功能图是从当前这份梯形图归纳出的参考图，
联锁、延时和扫描细节仍以梯形图为准；它不能导入、编辑或替代 TIA Portal 中的 SFC
程序。本工具不支持 SCL / FBD / HMI 组态，不与真实 PLC 通信，不能替代现场联调和
安全验收。

## 常见问题

**导出的 SVG 插进 Word / PowerPoint 还是矢量吗？**

是。SVG 里是线条、矩形和文本，不是放大的位图。Office 365、Office 2019 及更新版本
可以直接插入，拖大后边缘仍然清晰；更早的 Office 只认位图，改用 PNG。顺序功能图没有
标题，需要的话自己加一个文本框。

**SVG 怎么缩放？**

在浏览器或矢量软件里用 Ctrl + 滚轮、视图缩放，放到 A3 或投屏都不会糊。在 Word /
PowerPoint 里拖四角就能等比放大（按住 Shift 保持比例），不必重新导出。换电脑打开时
文字按系统字体显示，字宽可能略有差别，图仍是矢量。

**什么情况导出为空？**

顺序功能图至少要有一条带输出的网络。全是空白程序段时，页面会提示“这个工程还没有
梯形图网络”，不生成文件；完整程序 / 纯梯形图提示“没有可导出的程序段”或“有程序段
没有绘制内容”时，通常是工程还没有内容，或画布尚未绘制完成，稍等再试。另外，图片
生成期间导出入口会置灰并显示“正在导出，请稍候…”，这时连点不会重复下载；大图生成
较久时，可以点提示里的“取消导出”中止。
